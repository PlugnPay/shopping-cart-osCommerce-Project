PlugnPay Smart Screens v2 (ACH / eCheck) — osCommerce Project 2.2 (quick install)
=================================================================================

NOTE: These modules are discontinued. Prefer the current osCommerce packages:
https://github.com/PlugnPay/shopping-cart-osCommerce

1. Download oscproject_2.2_ach_ss2_module.zip (or use src/ss_ach/).
2. Copy files under catalog_root/ into the matching paths of your
   osCommerce Project catalog root.
3. Admin → Modules → Payment → install/configure PlugnPay ACH SS v2
   (plugnpay_ach_ss).
4. ACH data is collected on PlugnPay hosted Smart Screens v2
   (https://pay1.plugnpay.com/pay/) with pd_transaction_payment_type=ach.
5. ACH / eCheck must be enabled on the PlugnPay gateway account.
6. Authorization is auth-only (pb_post_auth=no). Capture / void / refund
   in PlugnPay Merchant Admin.

Full notes: src/ss_ach/readme_install.txt
