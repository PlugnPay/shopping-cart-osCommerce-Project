PlugnPay Smart Screens v2 (Credit Card) — osCommerce Project 2.2 (quick install)
================================================================================

NOTE: These modules are discontinued. Prefer the current osCommerce packages:
https://github.com/PlugnPay/shopping-cart-osCommerce

1. Download oscproject_2.2_cc_ss2_module.zip (or use src/ss_cc/).
2. Copy files under catalog_root/ into the matching paths of your
   osCommerce Project catalog root.
3. Admin → Modules → Payment → install/configure PlugnPay Credit Card SS v2
   (plugnpay_cc_ss).
4. Card data is collected on PlugnPay hosted Smart Screens v2
   (https://pay1.plugnpay.com/pay/).
5. Authorization is auth-only (pb_post_auth=no). Capture / void / refund
   in PlugnPay Merchant Admin.

Full notes: src/ss_cc/readme_install.txt
